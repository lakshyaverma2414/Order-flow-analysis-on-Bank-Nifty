# Visuals

The figures in this folder are intended to clarify the empirical result rather than decorate it.

Generated files:
- `correlation_distribution.png`: histogram of residual Pearson correlations with the sample mean marked
- `spearman_distribution.png`: histogram of residual Spearman correlations
- `cluster_comparison.png`: V2 cluster means with standard-deviation error bars
- `beta_vs_correlation.png`: scatter of spot beta versus residual Pearson correlation

These plots are produced by [scripts/generate_plots.py](../scripts/generate_plots.py) using the integrated result artifacts in the `results/` folder.
